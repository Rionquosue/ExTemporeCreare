# Textures

The Texture library's presets. Every image in this folder is a texture tile: PNG, JPEG, WebP, GIF or BMP. Its name in the library is the file name without its extension (`Cold Press Paper.png` shows as "Cold Press Paper").

The folder is packaged with the app (as the `textures` assets). Selecting a texture inserts a texture layer that tiles the image as a live pattern; its scale starts at one image pixel a point.

Only add images whose licence allows redistributing them with the app, and keep each image's licence or attribution beside it.
